Solmu 0.24.0 merges pins into favorites, finishes the Beeper-only cutover, and rebinds the keyboard: favorites keep Command+1..0, networks move to Option+1..0, and chat filters move to Command+Option+1..0 in the sidebar's order.

**Download:** see the assets below. The macOS build is universal (Apple Silicon and Intel), signed and notarized. Linux and Windows builds are unsigned.

## Since the last build (v0.23.1)

- **Pins are favorites:** chats pinned in Beeper appear as favorites and favorites sit at the top of the chat list; the rail's separate Pinned section is gone. Pin and unpin stay in the chat menus, folded into one Favorite/Unfavorite item; unfavoriting a pin-derived favorite unpins it in Beeper. Favorites carry a heart badge on their rows.
- **Favorites persist and reorder:** the favorites bar survives restarts (stored in the local archive) and drag-to-reorder works.
- **Keyboard rebind:** Command+1..0 opens a favorite by its place in the sidebar; Option+1..0 picks a network; Command+Option+1..8 picks a chat filter in the sidebar's order (All, Unread, Favorites, Read later, Reply later, Private, Groups, Channels) and Command+Option+9 toggles Unreplied. Command+U marks the open chat to read later, Command+I to reply later. Command+Option+Left/Right switch between linked numbers, replacing Command+Shift+A. Command+Shift+U/R/L, Command+L and the zoom keys are gone; Ctrl+Tab / Ctrl+Shift+Tab step through chats.
- **macOS labels:** shortcut help, tooltips and the command palette show Mac modifier glyphs, and "Toggle Chat List" names the sidebar toggle.
- **Beeper-only cutover finished:** the inherited native WhatsApp stack and call UI are out, attach and capture actions route through the Beeper backend, and the macOS bundle's tray login agent is restored.

## Known limitations

- The in-app updater still tracks upstream ZapFast releases, not this repository's; update checks from this build will not see this release.
- Linux packages still install zapfast-named desktop/icon files alongside the solmu binary (upstream packaging fixtures); Solmu branding there is a follow-up.
- Windows builds ship unsigned (Azure Artifact Signing is not configured on this repository), and its MSI assets are still zapfast-named.
- The What's New tour test fails on the Windows and macOS CI legs (pre-existing since v0.22.0, hover-cue timing); Linux legs pass. Being investigated.
