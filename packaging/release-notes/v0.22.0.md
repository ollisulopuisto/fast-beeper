Solmu 0.22.0 is the first Developer ID signed and notarized build of the Beeper client: the macOS DMG installs without the Gatekeeper warning.

**Download:** see the assets below. The macOS build is universal (Apple Silicon and Intel), signed and notarized. Linux and Windows builds are unsigned.

## Since the last build (2026.11.4.3)

- **Media sending:** images without a bundled decoder (AVIF paste, HEIC) convert to photos the networks accept; videos and audio phones cannot play are transcoded through ffmpeg; animated and transparent images keep their original files. (#161, #163)
- **Message text:** server-escaped entities (`&amp;` and friends) render decoded in plain bodies, and address-links no longer repeat. (#160)
- **Responsiveness:** linked-chat scrolling no longer stutters on layout, and the chat list sorts against one preview per chat instead of cloning per comparison. (#165, #167)
- **Safety:** URLs with nested percent-encoded control characters are rejected before they reach desktop handlers. (#166)

## Known limitations

- The in-app updater still tracks upstream ZapFast releases, not fast-beeper's; update checks from this build will not see this release.
- Windows builds ship unsigned (Azure Artifact Signing is not configured on this repository).
- Native runtime acceptance on this exact build is pending; changes above are covered by automated tests and earlier manual runs.
