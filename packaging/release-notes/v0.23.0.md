Solmu 0.23.0 renames the app from ZapFast/Fast Beeper to Solmu. The app, packages, docs and release assets carry the new name; the macOS DMG is signed and notarized as before.

**Download:** see the assets below. The macOS build is universal (Apple Silicon and Intel), signed and notarized. Linux and Windows builds are unsigned.

## Since the last build (v0.22.0)

- **Rebrand:** the app, CLI, installer and docs are now Solmu. (#170)
- **No data migration:** existing installs keep working. The data directories, the macOS bundle identifier, keychain entries and the Beeper launcher identity are unchanged on purpose, so settings, sessions and archives carry over. (#170)
- **Settings:** the Giphy key is read from `SOLMU_GIPHY_KEY`, still falling back to `ZAPFAST_GIPHY_KEY` and `FASTSAPP_GIPHY_KEY`. (#170)
- **Release pipeline:** the Windows packaging no longer publishes to the upstream ZapFast project. (#169)

## Known limitations

- The in-app updater still tracks upstream ZapFast releases, not this repository's; update checks from this build will not see this release.
- Linux packages still install zapfast-named desktop/icon files alongside the solmu binary (upstream packaging fixtures); Solmu branding there is a follow-up.
- Windows builds ship unsigned (Azure Artifact Signing is not configured on this repository).
- Native runtime acceptance on this exact build is pending; changes above are covered by automated tests and earlier manual runs.
