ZapFast 0.21.0 brings the combined sidebar and the command palette, and repairs the attachment upload request that WhatsApp rejected.

**Download:** see the assets below.

## New

- **Command palette (Ctrl+P):** find chats, apply list filters and run common actions from one keyboard-first overlay.
- **Combined sidebar:** network and account filters moved into the filter chip row, pinned chats show as regular rows at the top of the list, and Calls stays reachable in the rail with Beeper accounts.
- **Resize the chat list** by dragging its edge. (#35)

## Fixed

- **Attachment uploads to WhatsApp no longer send the request shape that was rejected** with "Attachment send returned", and a failed send keeps your staged files instead of dropping them. Covered by automated tests; a live send is what settles it. (#37)
- **The sidebar restores correctly** in narrow windows and with the list hidden, and the account avatar keeps its real size and click target. (#36, #38, #41)
- **Settings rows give their title the room the control actually leaves,** so titles like "Fetch older history" are no longer cut short at narrow widths. (#41)

## Known limitations

- A report from the previous trial build (2026.10.30.1) that clicking a staged photo's edit button did nothing could not be reproduced. The click-to-cropper action is covered by automated interaction tests in this release; editing in a live install has not been re-verified.
